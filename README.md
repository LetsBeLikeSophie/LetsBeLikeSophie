#### Things I've built

| Project | What it does | Stack |
| --- | --- | --- |
| [My Little Sessions](https://github.com/LetsBeLikeSophie/My-Little-Sessions) | A pixel-art office where every Claude Code session is a tiny coworker | Electron |
| [My Little Mods](https://github.com/LetsBeLikeSophie/My-Little-Mods) | Side-panel mods for Claude Code: an RPG campsite or a clean dashboard | Claude Code plugin |
